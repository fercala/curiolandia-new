# Curiolandia (nueva)

Nueva versión de [Curiolandia 3D](https://github.com/fercala/curiolandia-3d), el juego de temas de Educación Infantil
(3, 4 y 5 años) con Tito como guía, rehecha en TypeScript con arquitectura limpia.

Todavía no hay código: el plan está en [docs/PLAN-MIGRACION.md](docs/PLAN-MIGRACION.md) y los principios del proyecto en
[docs/CONSTITUCION-BORRADOR.md](docs/CONSTITUCION-BORRADOR.md).
